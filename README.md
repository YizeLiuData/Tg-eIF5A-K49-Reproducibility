# Tg-eIF5A-K49-Reproducibility
Repository of Ribo-seq data analysis scripts for the study: "eIF5A K49 acetylation controls the tachyzoite–bradyzoite transition of the zoonotic parasite Toxoplasma gondii"

This repository contains the scripts required for Ribo-seq, codon occupancy, state score, adaptive pausing of ribosomes (APR), and pre-ranked GSEA analyses as presented in the manuscript. It includes all necessary code, configuration files, and environment specifications.
